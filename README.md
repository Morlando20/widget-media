# MorlDesigns widget media

Animation clips (alpha WebM) that MorlDesigns StreamElements widgets load at runtime. The widgets try their main host first and fall back to these copies through jsDelivr.

- `wowcam/`: WoW Forever Cam Frame alert clips (coins, gift boxes, dice in 16:9, 1:1 and 9:16).

There is no code to install. Each widget pins an exact commit, so the files it uses never change. Do not delete or rename files here: sold widgets load them.
